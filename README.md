# 4PLAY — Nikunj Sharma

Portfolio site for **4PLAY**, the DJ persona of Nikunj Sharma: hypnotic techno, rominimal, deep grooves and psychedelic textures from New Delhi to the Himalayas.

## Concept: Third Eye

The triangle-and-eye from the "A" of the 4PLAY logo drives the whole site. It's the preloader, the 3D hero object, the pattern grid, the section-wipe transition and the photo mask.

| Section | What it does |
| --- | --- |
| Preloader | The mark draws itself, the eye opens, then the camera dives through the pupil into the hero |
| Hero | Three.js scene: the booth photo as a grain-duotone shader (pointer lens, RGB split, breathes at 124 BPM) and a chrome triangle-eye whose pupil follows the cursor |
| Menu | Fullscreen I–V menu that opens with a triangle wipe; photos swap on hover |
| Venues | Outline and filled marquees of every venue played; scroll speed pushes them |
| Live set | Featured Dharamkot set over an animated triangle/eye pattern grid |
| Triangle wipe | The brand triangle grows until it becomes the next section |
| Latest sets | Audiomack mixes open in a docked player; YouTube sets open in a video dialog |
| Light desk | Six real faders (Hypnotic, Groove, House, Psychedelic, High Energy, The Vibe) mix the stage light colour, the lead photo and the BPM |
| Quote / Artist | Photo inside a triangle mask; parallax collage over outlined serif type |
| Booking | Email, WhatsApp, EPK, tech rider |

## Stack

- Next.js 16 (App Router, static) + React 19 + Tailwind CSS 4
- GSAP + ScrollTrigger for motion, Lenis as the only smooth-scroll engine
- Three.js (vanilla, one canvas) for the hero
- Iconify: Solar for interface icons, Simple Icons for platform marks (generated by `npm run icons` into `src/lib/icons.ts`)

## Develop

```bash
npm install
npm run dev
```

All copy and media references live in `src/lib/content.ts`.

## Accessibility and fallbacks

- Under `prefers-reduced-motion`, there's no preloader, no smooth scroll and no WebGL: a static duotone poster replaces the canvas and all content renders in its final state.
- Split headings keep their full text for screen readers.
- The menu traps focus and closes on Esc; the video dialog uses native `<dialog>`.
- If WebGL is unavailable or the context is lost, the hero falls back to the poster.
